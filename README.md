# Topics in Advanced Model Rocketry

A new typeset version of the book now that it has been released to the public domain.

I'm doing this because I've wanted to for many years, since I first checked out the book from my college's Inter-Library Loan. I took pictures of all the pages and then never started because didn't know how to set up OCR and I was worried about how to handle copyright stuff. Now that a nicely scanned version has been released I'm just gonna go for it.

I've also been wanting to play around with local AI models for OCR and learning how to typeset beautiful books in Typst.

Big thanks to Gordon K. Mandell, George J. Caporaso, and William P. Bengen for writing the book and to Christopher L. Feyerchak for digitizing it.
